# FixFlow 🔧
> *Paste your error. Get your fix.*

FixFlow is an AI-powered developer tool that takes a pasted error message or problem description and returns a direct, synthesized solution — built on top of a Stack Overflow Q&A dataset enhanced with NLP, semantic search, and RAG generation.

---

## 🚀 Features

| Feature | Description |
|---|---|
| **Smart Search** | Semantic search using sentence embeddings instead of just keywords |
| **Tag Predictor** | Predicts relevant tags (e.g. android, kotlin, gradle) from the user's problem |
| **Error Parser** | Extracts error codes, version numbers, and class names from raw error text |
| **Answer Fusion** | Merges answers from similar questions into one unified answer pool |
| **Confidence Guard** | Detects when no good match exists and asks the user to refine their input |
| **Solution Synthesizer** | Uses RAG + LLM to generate one direct, sourced fix instead of a list of threads |
| **Smart Deduplicator** | Detects and merges near-duplicate questions using embedding similarity |
| **Source Tracer** | Shows the user exactly which Stack Overflow threads the answer came from |
